# hallo-rust

Repo latihan belajar bahasa pemrograman Rust.

Isinya adalah eksperimen dan contoh kecil yang ditulis sambil belajar — mulai dari
syntax dasar, ownership, borrowing, sampai konsep yang lebih lanjut. Bukan proyek
aplikasi, jadi tidak ada target fitur atau arsitektur tertentu.

## Cara menjalankan

Pastikan Rust sudah terpasang lewat [rustup](https://rustup.rs), lalu:

```bash
cargo run
```

## Cara compile

```bash
cargo build          # build debug
cargo build --release  # build release
```

## Konvensi repo ini

- Setiap konsep dipelajari lewat kode langsung, bukan hanya teori.
- Kode boleh sederhana atau setengah jadi — tujuannya belajar, bukan produksi.
- Komentar dipakai untuk mencatat apa yang sedang dipahami atau diragukan.
